## 🛠️ Features & Architecture

1. **Brand Identity & Aesthetic**:
   - Modern industrial charcoal/navy theme with racing red and amber call-to-action accents.
   - Glassmorphic card styling, metallic textures, and subtle CSS mesh patterns.
2. **Dynamic Shop Status**:
   - Live Pacific Time (Las Vegas) calculation showing "Open Now • Closes at 6:00 PM" with pulsing green indicator or next day opening hours.
3. **Interactive Coupon Claim Flow**:
   - Featured **$29.95 Synthetic Blend Oil Change & Brake Special** with 1-click coupon claim.
   - Auto-scrolls to the booking form, pre-populates service selection, applies the promo code (`OIL2995`), and displays an active coupon badge.
   - Additional coupon cards for $20 OFF Brakes, Free Check Engine Light Scan, and $50 OFF Major Repairs.
4. **Comprehensive Services Grid**:
   - 6 detailed service modules: Oil & Filter, Brake System Repairs, Advanced Diagnostics, Engine & Transmission, General Maintenance, Suspension & Steering.
   - Real-time category filtering tabs (Maintenance, Brakes, Diagnostics, Engine).
5. **Verified Customer Social Proof**:
   - Authentic review cards highlighting Antonio (Toni) and Lorenzo.
   - Google & Yelp 5.0 Star verification trust badges.
6. **Location & Interactive Google Map**:
   - Embedded responsive Google Map centered on 3100 W Sirius Ave Ste 107B.
   - One-tap "Get Directions (Google Maps)" navigation button.
7. **High-Converting Appointment & Free Estimate Form**:
   - Real-time client-side validation and phone auto-masking `(702) xxx-xxxx`.
   - Date picker with past date restrictions.
   - Interactive modal confirmation popup generating a unique reference number (e.g. `FIA-89102-XXXX`) with quick callback & directions options.
8. **Mobile First & Accessibility**:
   - Sticky tap-to-call mobile bar.
   - Responsive slide-out navigation drawer.
   - Schema.org `AutoRepair` JSON-LD Structured Data for local SEO rankings in Las Vegas.

## 💻 Local Testing & Preview

To preview the website locally:

```bash
# Navigate to project folder
cd "fix-it-all-auto-repair"

# Run a local Python HTTP server
python -m http.server 8080
```
Then open [http://localhost:8080](http://localhost:8080) in your browser.
